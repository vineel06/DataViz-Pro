🚀 Quick Start Guide
For End Users (No technical skills needed)
Method 1: Use Online Version
Open your web browser (Chrome, Firefox, Edge, Safari)
Go to your deployed URL
Start uploading Excel files immediately - no signup needed!

Method 2: Run Locally on Your Computer
Windows Users:
bash
1. Download the DataViz-Pro folder to your computer
2. Extract the ZIP file (if compressed)
3. Navigate to the DataViz-Pro folder
4. Double-click on index.html
5. Your default browser will open automatically

Mac Users:
bash
1. Download the DataViz-Pro folder
2. Extract the ZIP file
3. Open Finder and go to the DataViz-Pro folder
4. Right-click index.html → Open with → Choose your browser

Linux Users:
bash
1. Download the DataViz-Pro folder
2. Open terminal in the folder
3. Run: firefox index.html
   or: google-chrome index.html

For Developers
Option 1: Python (Easiest)
bash
cd DataViz-Pro
python -m http.server 8000
# Open browser to: http://localhost:8000

Option 2: VS Code Live Server
bash
1. Open DataViz-Pro folder in VS Code
2. Install "Live Server" extension
3. Right-click on index.html
4. Click "Open with Live Server"

Option 3: PyCharm
bash
1. Open PyCharm
2. File → Open → Select DataViz-Pro folder
3. Right-click on index.html
4. Select "Open in Browser"
